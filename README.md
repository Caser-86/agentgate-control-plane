# AgentGate

AgentGate is a local-first control plane that makes autonomous agent actions observable, policy-governed, approval-gated, resumable, and auditable.

The repository is intentionally scoped to agent action governance: it does not provide search, RAG, intelligence collection, or report generation.

## Quick start

Backend and frontend setup instructions will be completed with the local demo packaging milestone. The deterministic mock provider is the default and requires no API key.
