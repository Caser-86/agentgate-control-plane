# 文件动作治理说明

## 目标

AgentGate 的文件治理不是全盘杀毒，也不是 Windows 内核拦截器。它解决的是一个更具体、可落地的问题：当一个 Agent 通过 AgentGate 请求处理本机文件时，系统能够在真正产生副作用之前做路径校验、策略判断和人工审批，并在执行后留下可核验的证据。

## 受控对象

只有登记在“工作区”中的目录才受理文件动作。工作区由管理员创建，包含：

- 名称；
- 本机根目录；
- 一组保护规则；
- 同卷隔离目录；
- 当前版本号和启用状态。

Agent 只能传入工作区 ID 和相对路径，不能直接传入任意绝对路径。API 和 Native Worker 都会校验相对路径，拒绝 `..`、绝对盘符、UNC 路径、设备名和不安全的重解析路径。

## 默认保护规则

默认规则包括：

```text
.git/**
.agentgate/**
.env
.env.*
*.key
*.pem
credentials.*
protected/**
```

命中保护规则的隔离动作直接拒绝：不创建控制任务、不调用 Worker、不移动文件。拒绝结果会写入动作状态和审计，但不会写入文件内容。

## 支持的动作

### `file.inspect.v1`

只读检查文件是否存在、大小、修改时间和 SHA-256 摘要。返回值不包含文件正文，适合先确认目标再决定后续动作。

### `file.quarantine.v1`

将工作区内的普通文件移动到工作区对应的同卷隔离目录。该动作默认需要管理员批准。移动前会记录动作版本和参数摘要，移动后会记录隔离相对路径、摘要和大小。

受保护文件、非法路径、停用工作区和不存在的工作区不会进入执行队列。

### `file.restore.v1`

使用隔离记录恢复原相对路径。恢复同样需要管理员批准。若原路径已有文件，系统不会覆盖它，而是返回目标冲突结果，要求人工决定如何处理。

## 状态和副作用

动作状态与磁盘副作用分开保存。常见状态如下：

```text
denied             策略拒绝，没有任务和磁盘副作用
pending_approval   等待管理员决定
approved/queued    已批准，等待 Native Worker
running            Worker 已开始处理
succeeded          已取得可信的执行结果
failed             明确失败或恢复冲突
manual_review      执行状态不确定，停止自动重试
```

API 重启、Worker 重启或租约过期时，系统不会把“任务已经排队”误报成“文件已移动”。执行过程中的不确定状态会转人工复核，避免崩溃后无界重试写操作。

## 幂等和重复提交

外部 Agent 必须为文件动作提供 `Idempotency-Key`。同一个 client 在相同幂等键下重复提交同样参数，会得到原动作；如果把同一个幂等键用于不同路径或动作，API 返回冲突，不会修改原动作。

审批接口使用条件状态转换。重复点击批准、批准后再拒绝、过期后批准都会失败，不会生成第二个 Worker 任务。

## 审计和脱敏

审计记录包含动作 ID、策略决定、审批结果、任务 ID、结果摘要和游标。以下内容不会返回给外部 Agent 或前端：

- 文件正文；
- 原始 Worker 异常堆栈；
- client token、Worker token、管理员密码和 API key；
- 不必要的绝对工作区根路径；
- 不受控的命令字符串。

管理员工作区页可以显示本机根目录，这是为了让本机管理员确认边界；外部动作状态只使用相对路径。

## Worker 边界

Native Worker 是实际访问 Windows 磁盘的唯一执行者。它使用 DPAPI 保护本机凭据，按 API 授权的 workspace version 获取受控上下文，并在本地再次校验路径和保护规则。它不接受任意 Shell/PowerShell 命令，也不支持远程 API。

这个设计仍然有明确边界：如果某个程序不经过 AgentGate API，或者以管理员权限直接修改文件，AgentGate 当前无法拦截。要提供全局进程级阻止，需要单独的 Windows 安全产品和内核/EDR 能力，不属于本项目的承诺。

## 面试展示建议

最短演示顺序是：

1. 运行 `scripts/demo.ps1`。
2. 在“安全演示”提交 `.env` 和 `demo.txt`。
3. 指出 `.env` 直接拒绝且没有 Worker 任务。
4. 打开“审批”，批准 `demo.txt`。
5. 展示文件从原路径移动到隔离区。
6. 恢复文件并展示摘要一致。
7. 打开“审计”，说明每个决策都有可追踪证据。

这套展示同时覆盖安全拒绝、人工控制、真实 Windows 副作用、恢复、幂等和审计，工程量与可见价值比较平衡。
